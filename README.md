# Reactive Computers — Cloudflare Pages

Mobile-first React/Vite storefront for Reactive Computers.

## Deploy
- `npm install`
- `npm run build`
- Deploy the project to Cloudflare Pages with build command `npm run build` and output directory `dist`.
